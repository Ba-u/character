# ComfyUI-CharacterParts v23

캐릭터 프롬프트를 **캐릭터(외형) / 감정 / 의상 / 배경 / 임신** 프리팹으로 나눠 관리하고,
노드 버튼으로 여는 **프리팹 매니저** 창에서 한 번에 편집하는 ComfyUI 커스텀 노드입니다.

## 설치
`ComfyUI/custom_nodes/` 에 `ComfyUI-CharacterParts` 폴더째 넣고 ComfyUI 재시작.
노드 위치: `prompt/character prefab` (추가 의존성 없음)

## 노드
| 노드 | 설명 |
|---|---|
| **Character Prefab Composer 🧍** | 캐릭터·의상·배경·임신 프리팹 선택 + **감정 여러 개** 선택 → 감정 × 임신 상태마다 1장씩 |
| **Character Load 📂** | 저장된 캐릭터(캐릭터·의상·배경·태그) 불러오기 + 감정·임신은 이 노드에서 선택. 의상·배경 교체 가능 |
| **Character Save 💾** | `character` 출력(또는 아무 텍스트)을 이름 붙여 저장 — **감정·임신 설정은 저장하지 않음** |
| **Character Codes 🏷** | `character` 출력에서 코드를 꺼내고 `format` 으로 코드 모양을 지정 |
| **Character Name Tools 🔢** | 이름/코드에 순차 번호 붙이기(1, 2, 3…), 숫자만 남기기, 문자만 남기기 |

### 출력 (모두 STRING)
`positive`, `negative`, `character`, `code`,
`character_code`, `emotion_code`, `outfit_code`, `pregnancy_code`, `emotion_name`, `width`(INT), `height`(INT), `extra_path`, `save_path`
- 코드마다 출력구가 따로 있어서 원하는 코드만 바로 연결할 수 있습니다
- `positive` / `negative` → 기본 **CLIP Text Encode** 에 연결 → KSampler가 항목 수만큼 생성
- `code` (예: `C01_O01_슬픔_PG01`) → Save Image 의 `filename_prefix` 등에 연결
- `character` → Character Save / Character Codes 에 연결

## 노드 안 감정 패널
Composer / Load 노드 안에 감정 칩 패널이 있습니다.
- **파란 칩 = 선택된 감정**, 흐린 칩 = 선택 안 됨. 칩을 클릭하면 바로 켜고 끕니다
- 칩에는 감정 이름(= 코드)이 표시되고, `⚙` = 그 감정에 그룹 설정이 있음 (마우스를 올리면 설정 내용 표시)
- 윗줄에 `감정 N개 선택 ⇒ M장 · 따로 실행/한 번에` 표시
- 프리팹 매니저 창 하단에도 **선택된 감정** 이 모든 탭에서 항상 보입니다 (클릭: 그 감정 편집, ✕: 선택 해제)

## 정렬 순서
이름 속 숫자는 **숫자 크기대로** 정렬됩니다: `1 무표정, 2 기쁨, … 9 당황, 10 울음, 11 화남`
(노드 감정 칩, 매니저 목록, 드롭다운, 선택된 감정 칸, 실제 생성 순서 모두 동일. `emotions` 칸에 순서를 섞어 적어도 숫자 순으로 생성)

## 감정 폴더
- 감정 편집 화면의 **📁 폴더** 칸에 폴더 이름을 적으면 그 폴더로 들어갑니다 (`전투/분노` 처럼 하위 폴더 이름도 가능)
- 매니저 감정 목록이 폴더별로 묶여 보이고, 폴더 제목을 누르면 접기/펼치기
- 노드 감정 패널도 폴더별로 줄이 나뉘고, 주황색 **📁 폴더 칩**을 누르면 그 폴더 감정을 한 번에 켜기/끄기
- 폴더는 정리용입니다 (저장 경로는 '💾 추가 경로' 에서 따로 지정)

## 📊 표로 편집 (스프레드시트 창)
노드의 **📊 표로 편집 (새 창)** 버튼, 또는 매니저 창 오른쪽 위의 **📊 표로 편집** 버튼을 누르면
구글 시트처럼 생긴 **표 편집 창이 따로** 열립니다. 모든 값을 한 화면에서 고칠 수 있습니다.

- 탭: 감정 / 캐릭터 / 의상 / 배경 / 임신 / 감정 묶음 / 저장된 캐릭터
- 감정 탭은 37칸 — 이름·폴더·추가 경로·**묶음**·프롬프트·입힐 의상·해상도·배경·넣을 칸(✔/✕)·추가 프롬·그룹 설정까지 전부

### 📦 묶음별로 보기 (감정 탭)
감정 탭 위에 **묶음 칩 줄**이 나옵니다 — `전체 6` `밝은 2` `어두운 2` `묶음 없음 2`
- 묶음 칩을 누르면 **그 묶음에 들어있는 감정만** 표에 나옵니다 (다시 누르면 전체로)
- `묶음 없음` 은 어느 묶음에도 들어있지 않은 감정만 보여줍니다
- 칩 옆 숫자는 그 묶음의 감정 개수이고, 묶음이 바뀌면 바로 갱신됩니다
- 검색과 함께 쓰면 둘 다 만족하는 행만 나옵니다
- **묶음 칸**에 묶음 이름을 쉼표로 적으면 그 감정이 해당 묶음에 들어가고, 비우면 모든 묶음에서 빠집니다
  (없는 묶음 이름은 무시하고 알려줍니다 · 감정 묶음 탭에서 먼저 만들어 주세요)
- 왼쪽의 **번호·이름 칸은 고정**되어 오른쪽으로 스크롤해도 어느 행인지 보입니다

### 조작
| 키 | 하는 일 |
|---|---|
| 방향키 · `Tab` · `Enter` | 칸 이동 |
| 글자 입력 · `Enter` · 더블클릭 | 편집 시작 (`Esc` 취소) |
| `Shift`+방향키 / `Shift`+클릭 | 여러 칸 선택 |
| `Ctrl`+`C` / `Ctrl`+`V` | **엑셀·구글 시트와 표 그대로 복사/붙여넣기** (탭 구분) |
| `Delete` | 선택한 칸 비우기 |
| `Ctrl`+`Z` | 되돌리기 |
| `Ctrl`+`F` | 검색 |

- ✔/✕ 칸은 클릭하면 바뀌고, 드롭다운 칸(입힐 의상·배경 종류 등)은 목록에서 고릅니다
- 왼쪽 번호를 누르면 행 전체 선택 → **＋ 행 추가**, **🗑 선택 행 삭제**
- 행을 고른 뒤 **🔢 이름 숫자 지우기** / **🔤 이름 문자 지우기** 로 이름을 한 번에 정리

### 표 편집 창의 도구 (매니저와 같은 기능)
| 버튼 | 하는 일 |
|---|---|
| **＋ 행 추가** | 새 항목 만들기 |
| **⎘ 복제** | 고른 행(없으면 보이는 행 전체)을 `_복사` 를 붙여 복제 |
| **🔢 번호 매기기** | 아래 참고 |
| **✨ 추가 프롬 만들기** | (캐릭터 탭) 이름을 붙인 추가 프롬 칸을 새로 만듦 — 값을 적으면 저장됨 |
| **✚/➖ 노드에서 켜기·끄기** | (감정 탭) 고른 감정을 ComfyUI 노드의 선택 목록에 넣고 뺌 |
| **🎛 그룹 설정** | (감정 탭) 여러 감정의 그룹 켜기/끄기 설정을 한 번에 — 아래 참고 |
| **🔢🔤 이름 숫자/문자 지우기** | 이름 정리 |
| **🗑 선택 행 삭제** · **↶ 되돌리기** | |

### 🔢 순차 번호 매기기
고른 행(없으면 지금 보이는 행 전체)에 **표에 보이는 순서대로** 번호를 붙입니다.
- **시작 번호**: `0` 을 넣으면 `0, 1, 2, 3 …` · `1` 이면 `1, 2, 3 …`
- **간격**: 2 면 `0, 2, 4 …` · **자리수**: 2 면 `01, 02, 03 …`
- **위치**: 이름 앞 / 이름 뒤 / 번호만 · **구분자**: 번호와 이름 사이 글자
- **기존 번호**: `바꾸기` 면 `05 기쁨` → `0 기쁨` 처럼 원래 번호를 갈아끼우고, `그대로 두고 덧붙이기` 면 앞에 더 붙입니다
- 적용 전에 `기쁨 ⇒ 0 기쁨` 처럼 전부 미리 보여줍니다

### 🎛 그룹 설정 일괄 적용
고른 행(없으면 지금 보이는 행 전체)의 **그룹 켜기/끄기 설정**을 한 번에 바꿉니다.
창을 열면 **지금 열려 있는 ComfyUI 워크플로의 그룹 목록과 현재 상태**를 읽어와 보여줍니다
(ComfyUI 창이 닫혀 있으면 이미 감정에 저장된 그룹 이름만 나옵니다 — 아래 칸에서 직접 적어 넣어도 됩니다).

그룹마다 고를 수 있는 값:

| 값 | 뜻 |
|---|---|
| **바꾸지 않음** | 그 그룹은 건드리지 않음 (기본값) |
| **설정 없음 (유지)** | 저장된 설정을 지움 → 그 감정에서는 그룹을 그대로 둠 |
| **켜기** | 그 감정을 뽑을 때 그룹을 켬 |
| **끄기 (뮤트)** · **끄기 (바이패스)** | 그룹을 뮤트/바이패스로 끔 |

- **📥 현재 워크플로 상태로**: 지금 워크플로에 보이는 그룹 상태(켜짐/뮤트/바이패스)를 그대로 집어넣습니다
- **모두 설정 없음** / **모두 바꾸지 않음**: 전부 한 번에 맞춤
- 적용하면 자동 저장되고, **↶ 되돌리기** 로 되돌릴 수 있습니다

### ⭐ 저장된 캐릭터 탭
저장된 조합의 **캐릭터·의상·배경 칸을 전부 고칠 수 있습니다** (매니저와 동일).
각 섹션의 **프리팹** 칸에서 이름을 고르면 그 프리팹 내용을 통째로 가져옵니다.
- 고친 값은 **자동 저장**되고(오른쪽 위에 저장 상태 표시), ComfyUI 노드와 매니저에 **즉시 반영**됩니다
- 반대로 ComfyUI에서 고친 값도 표 편집 창에 바로 나타납니다 (표에서 편집 중이면 덮어쓰지 않음)
- 구글 시트에 올리고 싶으면 표에서 `Ctrl`+`C` 로 복사해 시트에 붙여넣고, 고친 뒤 다시 복사해 표에 붙여넣으면 됩니다

## 매니저 목록 보기
- **☰ 간단히 / 자세히**: 이름만 한 줄로 보기 ↔ 설명까지 보기 (탭마다 따로 기억)
- **▸ 모두 접기 / ▾ 모두 펼치기**: 감정 폴더를 한 번에 접고 펼치기
- 보기 방식과 접은 폴더는 매니저 창을 닫았다 열어도 유지됩니다

## 일괄 작업 (여러 감정 한 번에)
매니저 😊감정 탭의 **☑ 여러 개 선택해서 일괄 작업** 버튼 → 목록에서 감정을 클릭해 고르거나, 폴더 제목 옆 체크박스로 폴더 전체 선택
- **📁 폴더로 이동** / 폴더에서 빼기
- **✎ 이름에서 지우기**: **🔢 숫자 지우기** / **🔤 문자 지우기** — 고른 감정 이름에서 숫자나 문자를 한 번에 제거
  (`1 무표정` → 숫자 지우기 `무표정` / 문자 지우기 `1`). 바뀔 이름이 버튼 옆에 미리 보이고, 실행 전에 한 번 더 확인합니다.
  감정 이름 = 감정 코드이므로 코드도 함께 바뀌며, 감정 묶음과 노드의 선택 목록도 새 이름으로 따라갑니다. 이름이 겹치면 `_2` 가 붙습니다
- **⎘ 일괄 복제**: 이름 앞/뒤에 붙일 글자(기본 `_복사`)와 복제본 폴더를 정해 복제. 이름이 겹치면 `_2`, `_3` 자동. 복제가 끝나면 복제본이 선택된 상태가 되어 바로 일괄 변경 가능
- **✎ 일괄 설정 변경**: 체크한 항목만 바뀝니다 — 추가 경로, 해상도, 배경 종류/프리팹, 의상 프리팹/코드, 전투, 가중치, 그룹 설정(지금 워크플로 상태로 / 지우기),
  캐릭터 칸·의상 칸·추가 프롬 (칩을 누를 때마다 `— 변경 안 함` → `✔ 넣기` → `✕ 빼기`)
- **노드에서 켜기/끄기**, **🗑 일괄 삭제**

## 전체 켜기/끄기 · 감정 묶음
- 노드 감정 패널의 **전체 켜기 / 전체 끄기** 버튼으로 모든 감정을 한 번에 켜고 끕니다
- **📦 감정 묶음**: 매니저의 `📦 감정 묶음` 탭에서 이름을 붙이고 묶을 감정을 골라 저장
  - 노드 패널과 매니저 감정 탭에 `📦 묶음이름` 버튼이 생기며, 누르면 묶음 전체를 켜고/끕니다
  - 버튼 색: **초록 = 묶음 전부 켜짐**, 파랑 = 일부만 켜짐, 점선 = 모두 꺼짐
  - 묶음 안 감정이 일부만 켜져 있으면 누를 때 나머지를 모두 켜고, 전부 켜져 있으면 모두 끕니다
  - 감정 이름을 바꾸거나 삭제하면 묶음에도 자동 반영
  - 기본 예시 묶음: 기본 표정(기쁨·미소·무표정), 부정 감정(슬픔·분노)
- **묶음 삭제 시 선택**: 묶음에 감정이 들어 있으면 삭제할 때 창이 떠서 고릅니다
  — **묶음만 삭제** (감정은 남김) / **묶음 + 감정 삭제** / 취소
  다른 묶음에도 들어있는 감정이 있으면 ⚠ 로 먼저 알려줍니다. 매니저와 표 편집 창 모두 같고,
  표 편집 창에서는 `Ctrl`+`Z` 로 묶음과 감정을 함께 되살릴 수 있습니다

## 여러 감정 → 여러 장
- 노드 안 감정 패널에서 클릭하거나, **😊 감정 편집 · 🗂 프리팹 매니저** 버튼 → 감정 탭 체크박스로 선택 (전체/해제 가능)
- `emotions` 칸에 직접 `기쁨, 슬픔` 처럼 감정 이름(= 감정 코드)을 적어도 됩니다
- `pregnancy_state` 가 **둘 다** 면 감정마다 임신 전/후 2장 → 예: 감정 3개 × 2 = 6장
- `run_mode`
  - **감정마다 따로 실행 (그룹 적용)** (기본): Run 을 한 번 누르면 감정(×임신 상태)마다 **별도 작업**으로 큐에 들어가
    결과물(에셋)이 각각 따로 나오고, 감정별 그룹 설정이 적용됩니다. 끝나면 그룹 상태는 원래대로 돌아옵니다
  - **한 번에 실행 (리스트)**: 작업 하나에서 리스트로 모두 생성 (그룹 설정 적용 안 됨)

## 감정별 그룹 켜기/끄기 (Fast Groups Muter 방식)
1. 매니저 😊감정 탭에서 감정을 고르면 **🎛 그룹 설정** 에 현재 워크플로의 그룹이 표시됩니다
2. 그룹마다 `유지 / 켜기 / 끄기(뮤트) / 끄기(바이패스)` 선택 후 저장
   - **📥 현재 상태 가져오기**: 지금 캔버스의 그룹 상태를 그대로 이 감정 설정으로
   - **▶ 지금 적용해보기**: 캔버스에 바로 적용해서 확인
3. `run_mode` 가 **감정마다 따로 실행** 이면 Run 할 때 감정마다 그 설정이 적용된 채로 큐에 들어갑니다
- 그룹은 **이름(제목)** 으로 연결되므로 같은 그룹 이름을 쓰는 워크플로라면 그대로 재사용됩니다
- 이 노드가 들어있는 그룹을 끄는 감정은 건너뜁니다 (⚠ 표시)
- 켜져 있는 출력 노드가 하나도 없으면 ComfyUI가 그 실행을 거부합니다
- **여러 감정에 한꺼번에** 같은 그룹 설정을 넣으려면 매니저의 **✎ 일괄 설정 변경** 이나
  표 편집 창의 **🎛 그룹 설정** 을 쓰세요 (→ [🎛 그룹 설정 일괄 적용](#-그룹-설정-일괄-적용))

## 코드
| 종류 | 형식 | 지정 방식 |
|---|---|---|
| 캐릭터 코드 | `C01` | 직접 입력, 비우면 자동 |
| 의상 코드 | `O01` | 직접 입력, 비우면 자동 |
| 감정 코드 | `기쁨` | **감정 이름이 곧 감정 코드** (이름을 바꾸면 코드도 같이 바뀜) |
| 임신 전 코드 / 임신 후 코드 | `NP01` / `PG01` | 임신 프리팹마다 두 개, 직접 입력, 비우면 자동 |

- 같은 종류 안에서 코드가 겹치면 저장이 거부됩니다
- **Character Codes** 노드 출력: `code`, `character_code`, `outfit_code`, `emotion_code`, `pregnancy_code`, `emotion_name`, `pregnancy_state`
- `format` 으로 코드 모양 지정: `{character} {outfit} {emotion} {pregnancy} {emotion_name} {state} {background}(배경 이름) {bg_type}(대표/실내/실외)`
  (기본 `{character}_{outfit}_{emotion}_{pregnancy}`, 빈 코드는 구분자와 함께 생략)

## 이름 도구 (Character Name Tools 🔢)
`code` 나 `emotion_name` 을 연결해서 Save Image 의 `filename_prefix` 로 보내는 식으로 씁니다.
- `keep`: 그대로 / **숫자만 남기기** / **문자만 남기기** / 숫자 지우기 / 문자 지우기
  (예: `C01_O01_기쁨_PG01` → 숫자만 `01_01_01`, 문자만 `C_O_기쁨_PG`) · `keep_separators` 로 `_ - .` 유지 여부
- `numbering`: 번호 없음 / 뒤에 번호 / 앞에 번호 / 번호만 — `start`, `step`, `digits`(0 = 1,2,3 / 3 = 001,002), `separator`
- `counter`
  - **계속 이어서** (기본): 실행할 때마다 번호가 이어집니다 (감정마다 따로 실행해도 1, 2, 3, 4…).
    `start` 나 `step` 을 바꾸면 처음부터 다시 시작 (ComfyUI 재시작 시에도 초기화)
  - **실행마다 처음부터**: 매 실행 start 부터

## 캐릭터 / 의상 칸
- 캐릭터(외형): 기본, 머리카락, 앞머리, 눈, 얼굴/피부, **체형(앞)**, **체형(뒤)**, **나체(앞)**, **나체(뒤)**, ⚔ 전투
  (이전 버전의 체형 → 체형(앞), 나체 디테일 → 나체(앞) 으로 자동 이동)
- 캐릭터의 **✨ 추가 프롬**: `＋ 추가 프롬` 버튼 → 이름을 직접 정하고 긍정/부정 프롬을 입력. 여러 개 추가 가능
- 의상: 상의, 하의, **브라**, **팬티**, 다리/양말/신발, 액세서리

## 감정마다 넣을 프롬 고르기
매니저 😊감정 탭의 **🧩 이 감정에 넣을 프롬** 에서 감정마다 정합니다.
- **⚔ 전투 프롬 켜기/끄기**: 캐릭터의 '전투' 칸을 이 감정에 넣을지 (프롬프트에서는 감정·표정 뒤에 들어감)
- **캐릭터 칸 / 의상 칸**: 칩을 눌러 넣기(파랑) / 빼기(회색). `전부 넣기`, `전부 빼기`, `기본값` 버튼
- **✨ 추가 프롬**: 캐릭터에 만든 추가 프롬이 이름으로 나열됩니다. **모든 감정에서 기본은 꺼짐**, 켜고 싶은 감정에서만 켜세요
  (이름으로 연결되므로 같은 이름의 추가 프롬을 가진 다른 캐릭터에도 똑같이 적용됩니다)
- 기본값: 체형(뒤)·나체(앞)·나체(뒤)·전투·브라·팬티·추가 프롬은 **빼기**, 나머지는 넣기 (감정 없이 뽑을 때도 기본값)
- 노드 감정 칩의 `⚔` = 전투 켜짐, `✨` = 추가 프롬 켜짐. 마우스를 올리면 빼는 칸 목록이 보입니다

## 감정별 추가 경로 (저장 폴더)
매니저 😊감정 탭의 **📁 이 감정의 추가 경로** — 기본값은 **`점검중`**
- `extra_path` 출력 = 추가 경로, `save_path` 출력 = `추가 경로/코드` (예: `점검중/C01_O01_기쁨`)
- `save_path` 를 **Save Image 의 filename_prefix** 에 연결하면 `output/점검중/C01_O01_기쁨_00001_.png` 처럼 감정별 폴더에 저장
- `완료/전투` 처럼 하위 폴더도 가능. `기본값(점검중)` / `비우기` 버튼. 비우면 폴더 없이 `C01_O01_기쁨` 으로 저장
- 역슬래시(\\)는 / 로 바뀌고 `..` 같은 상위 폴더 이동은 제거됩니다
- 감정 없이 뽑을 때도 `점검중`
- Character Name Tools 에 `save_path` 를 넣어 번호를 붙인 뒤 filename_prefix 로 보내도 됩니다

## 캐릭터 의상 (기본 / 아이돌) + 감정별 의상
### 캐릭터에 의상 지정 — 매니저 👤캐릭터 탭의 **👗 이 캐릭터의 의상**
- **기본 의상**, **아이돌 의상** 두 칸에 의상 프리팹을 골라 둡니다 (캐릭터마다 따로)
- 감정에서 `캐릭터 기본 의상` / `캐릭터 아이돌 의상` 을 고르면 그 캐릭터에 지정된 의상이 입혀집니다
  → 캐릭터를 바꾸기만 하면 같은 감정 설정으로 각자의 옷을 입습니다

### 감정에서 고르기 — 매니저 😊감정 탭의 **👗 이 감정의 의상**
**입힐 의상** 드롭다운에서 하나를 고릅니다.

| 선택지 | 입는 의상 |
|---|---|
| (노드에서 고른 의상) | 노드의 `outfit` — 비어 있으면 캐릭터 **기본 의상** |
| 👤 캐릭터 기본 의상 | 캐릭터에 지정한 기본 의상 |
| 👤 캐릭터 아이돌 의상 | 캐릭터에 지정한 아이돌 의상 |
| 특정 의상 (의상 프리팹 목록) | 캐릭터와 상관없이 항상 그 의상 |

- **의상 코드**: 직접 적으면 의상은 그대로 두고 `code` / `outfit_code` 출력만 그 값으로 (예: 의상 칸을 뺀 감정에 `NUDE`)
- 캐릭터에 해당 의상이 지정돼 있지 않으면 노드 의상으로 대신하고 콘솔에 알립니다
- 노드 감정 칩에 `·기본옷`, `·아이돌`, `·O02`, `·NUDE` 처럼 이 감정이 입는 의상이 표시됩니다
- '넣을 프롬'의 의상 칸 넣기/빼기는 이 감정에서 입는 의상에 그대로 적용됩니다
- 일괄 설정 변경의 **👗 입힐 의상** 으로 여러 감정을 한 번에 바꿀 수 있습니다

## 해상도
- Composer / Load 노드의 `width`, `height` = 기본 해상도 (기본 1024×1024)
- 감정마다 **📐 이 감정의 해상도** (매니저 😊감정 탭): `노드 설정 따름` 또는 `직접 지정`
  - 빠른 선택: 1:1, 2:3/3:2, 3:4/4:3, 9:16/16:9, SD 세로/가로 · `⇄` 가로/세로 바꾸기 · 8의 배수로 자동 맞춤
- `width` / `height` 출력을 **Empty Latent Image** 의 width / height 에 연결하면 감정마다 다른 크기로 생성됩니다
- 노드 감정 칩에 `·768×1344` 처럼 감정 해상도가 표시되고, 패널 윗줄에 노드 기본 해상도가 보입니다

## 배경 (대표 / 실내 / 실외)
배경 프리팹마다 **대표 배경**, **실내 배경**, **실외 배경**, **공통**(조명·구도 등, 어느 종류든 붙음) 칸이 있습니다. 배경 코드는 없습니다.
- 감정마다 **이 감정의 배경** 에서 고릅니다 (매니저 😊감정 탭)
  - 배경 종류: 대표 / 실내 / 실외 / 없음
  - 배경 프리팹: 비워두면 노드에서 고른 배경, 지정하면 그 감정은 항상 그 배경
- 실내/실외 칸이 비어 있으면 대표 배경을 대신 씁니다
- 감정 없이 뽑을 때는 대표 배경
- 노드 감정 칩에 `·실내`, `·실외` 처럼 대표가 아닌 배경 종류가 표시됩니다
- 이전 버전 배경(장소/조명/구도)은 자동으로 대표 배경 + 공통으로 옮겨집니다

## 임신 프리팹
프리팹마다 **임신 전** (코드·프롬프트·네거티브)과 **임신 후** (코드·프롬프트·네거티브)를 따로 가집니다.
Composer의 `pregnancy` 로 고르고 `pregnancy_state` 로 임신 전 / 임신 후 / 둘 다 를 선택합니다.

프롬프트 순서: 품질 → 캐릭터 → 임신 → 감정 → 추가 표정/포즈 → 의상 → 배경 → 추가 태그

## 캐릭터 저장 범위
**현재 조합을 캐릭터로 저장** 과 **Character Save** 는 캐릭터(외형)·의상·배경·품질/추가/표정 태그·네거티브만 저장합니다.
감정 선택과 임신 설정은 저장하지 않으며, Character Load 에서 `emotions`, `pregnancy`, `pregnancy_state` 로 고릅니다.
(이전 버전에서 감정·임신이 함께 저장된 캐릭터도 불러올 때는 무시됩니다)
