표 편집 도움말

  • ↑↓←→ 칸 이동 · Tab 오른쪽 · Enter 아래
  • 글자를 바로 입력하거나 Enter / 더블클릭으로 편집, Esc 취소
  • Shift+방향키 또는 Shift+클릭으로 여러 칸 선택
  • Ctrl+C / Ctrl+V — 엑셀·구글 시트와 표 그대로 복사/붙여넣기
  • Delete 선택한 칸 비우기 · Ctrl+Z 되돌리기
  • ✔/✕ 칸은 클릭하면 바뀝니다 · 왼쪽 번호를 누르면 행 전체 선택
